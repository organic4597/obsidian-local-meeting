# 0.3.0 사용성 개선 검증

2026-10-25, 설치된 Obsidian 1.14.5 / macOS 26.6에서 확인했다. 이전 화면을 캡처하고 확인한 뒤 동일한 실제 앱에서 결과를 점검했다. 소스·자원은 Obsidian 기본 컴포넌트, 아이콘과 테마 변수를 사용했다.

| 흐름 | 이전 문제 | 개선 결과 | 상태 |
| --- | --- | --- | --- |
| 녹음과 참여자 편집 | 동등한 시작·중지·복구 버튼, 원시 화자·구간 ID, 반복 입력 폼 | 한 개의 시작/종료 버튼, 대상 노트 표시, 참여자 이름과 Enter 저장, 접힌 발언별 화자 선택 | 양호 |
| 캘린더 보기 | 팝업을 열면 긴 생성 폼부터 표시, 별도 조회 버튼 | 열자마자 월간 일정 자동 조회, 날짜별 목록과 상세 보기, 개별/전체 캘린더 선택 | 양호 |
| 일정·할 일 입력 | 보기와 입력 혼재, 필드 라벨·오류·저장 상태 부족 | 별도 입력 팝업, 선택 날짜 기본값, 선택적 할 일 기한, 인라인 오류와 저장 중 중복 제출 방지 | 개선됨 |

## 실제 앱 확인

1. 참여자 이름을 Enter로 저장했을 때 합성 음성 테스트 노트의 해당 화자 발언 두 곳이 변경됐다. 재시작 후 참여자 목록 표시도 확인했다.
2. 연결된 7개 캘린더를 조회하고 전체 캘린더 보기에서 해당 월 공휴일 3건을 표시했다. 날짜 선택 후 1개 일정 목록과 상세 팝업을 확인했다. 선택된 iCloud 캘린더의 빈 날짜도 오류와 구별해서 표시했다.
3. 방향키로 다음 날짜, PageDown으로 다음 달 이동 후 날짜 포커스가 유지됐다. 새 일정은 선택한 날짜의 09:00–10:00으로 채워졌고 빈 제목 저장을 거부했다.

날짜의 오늘·선택 상태를 분리하고 필드 라벨, 상태 알림, 키보드 포커스 스타일을 추가했다. 전체 접근성 표준 준수를 검증한 것은 아니며 화면 읽기 도구, 확대 배율, 모든 테마의 대비와 다른 플러그인의 단축키 충돌은 추가 확인 대상이다.

자동 검사: TypeScript 19개, Python 6개 통과. 월/연도 경계, 윤년, 자정 종료 배제, 종일·여러 날짜 일정, 입력 검증과 기본 시간을 포함한다. 실제 iCloud 이벤트를 임의 생성하지 않았으며 외부 기기까지 동기화 완료를 확인하지 않았다. 요약 자동 생성과 실제 다인 회의의 화자 구분 정확도는 이번 UI 작업의 완료 범위가 아니다.

4. 최종 설치 후 두 화자 합성 WAV 19.386초를 별도 노트에서 다시 전사했다. 발언 3개가 화자 1→2→1로 기록되고 큐가 모두 비워졌다. 드롭다운에서 한 발언의 화자를 변경·복원하고 기한 없는 테스트 할 일을 노트에 저장했다.
5. `⌘⌥C` 실제 키 입력으로 팝업을 열었고, 새 일정·할 일의 제목 입력에 자동 포커스가 놓이는 것을 확인했다. 저장된 오버레이 위치와 모델 경로를 보존했다.
