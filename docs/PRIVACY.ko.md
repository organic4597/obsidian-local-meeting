# 개인정보·외부 파일 접근 안내

Local Meeting은 사용자 추적·클라이언트 텔레메트리를 구현하지 않는다. 모델 라이브러리의 첫 실행 다운로드나 외부 서비스 정책까지 이 문서로 보증하지는 않는다. 배포 전 외부 의존성 동작을 별도로 검증한다.

- 로컬 입력: 마이크, 선택한 시스템/앱 오디오. 녹음 권한을 허용하고 사용자가 시작한 회의에서 사용한다.
- Vault 내부: 사용자가 선택한 회의록 폴더의 원문·AI 정리·직접 필기를 읽고 갱신한다. 수동 교정 보호 경로를 유지한다.
- Vault 외부: 오디오 저장 폴더에 WAV·전사·큐·복구 메타데이터, 사용자 앱 데이터 폴더에 연결 인덱스를 보관한다. 설치된 Python·모델·지원 파일도 Vault 외부에서 읽거나 실행한다. 대용량 오디오/모델을 Vault 동기화와 분리하고 로컬 복구를 제공하기 위해 필요하다.
- 선택적 음성 프로필: 이름에 연결된 음성 특징을 로컬 파일로 저장한다. 회의 참여자에게 알리고 동의받은 경우에만 수집을 켠다. OpenAI로 음성 특징을 보내지 않는다.
- OpenAI: 브라우저 로그인에 auth.openai.com, 선택적 요약·모델 목록 등에 api.openai.com을 사용한다. 요약에는 현재 문서·필기·화자 이름·발언/시각 정보를 전송한다. 전송 버튼 또는 종료 후 자동 정리 설정에 따라 요청하며 현재 자동 정리 기본값은 켜짐이다. 계정을 연결하지 않으면 외부 요약을 사용할 수 없다. 비용·계정 사용 한도와 보관 정책은 제공자의 정책을 확인한다.
- 인증: OpenAI 자격정보는 Obsidian SecretStorage에 저장한다. 설치 ZIP·회의 노트에 포함하지 않는다. Hugging Face 모델 동의·다운로드 인증은 외부 도구에서 사용자가 진행한다.
- 캘린더: 로컬 EventKit으로 Mac에 연결된 캘린더를 읽고 사용자가 확인한 일정을 쓴다. Apple ID 비밀번호를 플러그인이 저장하지 않는다. iCloud 서버 동기화는 macOS 계정 설정을 따른다.
- 삭제: 노트만 지워도 Vault 외부 녹음·큐·음성 프로필은 자동으로 지워지지 않는다. 사용자 저장 위치를 확인한 뒤 직접 관리한다. 플러그인 제거로 외부 자료를 자동 삭제하지 않는다.
