# 문장 재생 · 잠정 화자 · 인물별 요약 (0.13.0-beta.3)

이 문서는 beta.3의 이력입니다. beta.4에서는 [스트리밍 전사](STREAMING-NOTES.ko.md)를 적용해 화자 결과를 기다리지 않고 텍스트를 표시합니다.

## 문장 클릭 재생

새 AI 정리 노트의 결정·할 일·일정·확인사항·인물별 발언 요약은 문장에 녹음 범위를 연결한다. 마우스를 올리면 시간 범위가 툴팁으로 보이며, 클릭하면 해당 음성을 재생한다. 서로 떨어진 여러 구간이면 선택 창을 먼저 연다. 읽기 모드와 Live Preview에서 사용한다. 소스 모드와 커서를 놓고 편집하는 링크에는 Markdown 문법이 보일 수 있다.

기존 정리는 상세 보기의 ‘문장 클릭으로 듣는 정리 노트 만들기’로 별도 복사본을 만든다. 원본과 수동 편집·체크 상태는 보존하며 AI를 재호출하지 않는다.

## 실시간 잠정 화자 구분

회의 시작 창에서 선택하는 시험 기능이다. 별도 프로세스의 Community-1/MPS가 최근 최대 24초를 4초 간격으로 분석한다. 새 창의 화자를 시간 중첩과 음성 특징으로 이전 잠정 번호에 연결한다. 다른 화자의 안정된 시작점을 발견하면 쉼이 없어도 전사 구간을 나눈다. 동시 발언은 겹침으로 표시하며 두 목소리를 분리 복원하지는 않는다. 인원 설정은 실시간 창에서는 최대값으로만 적용하며, 종료 후에는 선택한 최대/고정 정책으로 전체 녹음을 다시 분석한다.

현재 시험 구현은 최근 5초를 보류하므로 텍스트 표시에도 지연이 더해진다. 화자 분석은 첫 호출 약 6.97초, 이후 작은 표본 창에서 약 0.75~1.26초였으며 전체 지연이나 정확도 보증이 아니다. 첫 32초의 무음 출력 재처리 시험에서는 연속 발화와 모델 준비가 겹쳐 첫 전사가 약 32초에 도착했다. 발화 종료 대기(약 0.9초 쉼/최대 20초)도 표시 지연에 포함된다.

실제 두 사람의 끼어들기 정답 자료를 확보하지 못해 정확도는 측정하지 않았다. 잠정 번호는 실제 인물 신원이 아니며 이름 수정은 수동 배정으로 보호한다. 최대 수를 넘긴 새로운 후보는 기존 인물로 강제 배정하지 않고 미확정 처리한다. 종료 후 쓰이지 않는 잠정 번호를 정리한다. 분석 프로세스가 실패하면 전사를 계속하고 진단에 오류를 표시한다.

후속 개선 방향은 전사와 화자 확정을 완전히 분리하는 것이다. STT의 문맥 유지 스트리밍으로 임시 텍스트를 먼저 표시하고, 최근 임시 범위만 수정하며, 화자 결과는 별도로 나중에 갱신한다. 0.5~1초 입력과 1~2초 내 임시 표시를 목표로 하되 현재 성능 측정값으로 취급하지 않는다. 현재 버전에는 이 스트리밍 전환이 적용되지 않았다.

## 인물별 발언 요약

기존 OpenAI 정리 요청 한 번에 speakerSummaries를 함께 요청한다. 이름과 화자 ID를 입력으로 전달하고 핵심 의견·제안·질문·명시적으로 맡은 일을 해당 화자의 발언 근거와 함께 반환받는다. 서로 다른 화자의 근거를 혼합하거나 미확정·동시 발언을 특정 인물에게 붙인 결과는 거부한다. 모델의 의견 요약 정확도는 사용자가 검토해야 한다. 기존 수동 편집한 요약은 덮어쓰지 않으며 새 정리 노트에서 생성한다. 이전 저장 결과에는 이 항목이 없을 수 있다.

## 검사 범위

자동 검사와 로컬 실제 모델의 짧은 무음 재처리를 수행했다. 화자 교대/겹침 경계는 합성 시간 구간 단위 검사로 확인했다. 외부 스피커로 소리를 재생하지 않았으며 실제 회의 내용을 새로 API에 전송하지 않았다.
