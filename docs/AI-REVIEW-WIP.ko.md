# AI 검토·용어 후보 구현 현황

기준: 0.11.0, 작업 브랜치. 설치·배포 전 작업이다.

- OpenAI 회의 정리 요청에 용어 후보를 추가한다. 회의 텍스트의 근거에서 확인되지 않는 인식 표기는 버리고 후보만 회의별로 보관한다. 사용자가 범위와 표준 표기를 확인해 사전에 추가하기 전에는 인식 힌트나 교정에 반영하지 않는다.
- 구버전 정리에 용어 후보가 없는 경우 명시적 요청으로 별도 추출한다. 기존 요약과 메모를 변경하지 않는다.
- 검토 항목과 사용자 수정값을 회의별 로컬 파일에 저장한다. 검토한 내용은 새 정리 노트로 만들며 기존 노트를 덮어쓰지 않는다. 할 일을 회의 원문에 추가할 때는 명시적 동작을 요구한다.
- 일정은 편집 후 사용자가 저장한다. 같은 후보의 처리 상태를 먼저 기록해 응답 불명 시 자동 재시도하지 않고, 이전에 저장된 같은 제목 후보를 경고한다. 기존 버전이나 다른 앱에서 저장한 일정은 이 로컬 검토 기록에 없으므로 캘린더에서 직접 중복 확인이 필요하다.
- 종일 일정은 사용자가 선택하며, 마지막 표시 날짜는 포함하고 EventKit 종료일은 다음 날 0시로 전달한다.

## 검증 및 미완료

- `npm run check`: TypeScript 101개, Python 49개 통과. CalendarBridge Swift 컴파일 통과. 합성 데이터와 모의 전송 검사이며 실제 OpenAI 요청이나 캘린더 일정 생성 확인은 아니다.
- Core Audio 프로토타입은 마이크와 시스템 탭의 비공개 집계 장치를 만들었지만 캡처 시작이 `MACH_RCV_TIMED_OUT`으로 실패했다. 단독 마이크 입력은 동작했다. 화면 제어에서도 ScreenCaptureKit 캡처 오류가 발생했다. 원인은 확인되지 않았고 시스템 오디오 기능은 구현·검증 완료가 아니다.
- 실제 Obsidian UI, OpenAI 연결, EventKit 저장과 시스템 오디오 동시 녹음의 종단간 검증이 남아 있다. 이 브랜치를 릴리즈나 설치본으로 간주하지 않는다.
