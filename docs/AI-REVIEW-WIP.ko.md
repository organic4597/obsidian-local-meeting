# AI 검토·용어 후보 구현 현황

기준: 0.11.0. 작업 브랜치의 0.12.0-beta.1을 사용자 Mac에 설치해 시험했다. 정식 릴리즈는 아직 하지 않았다.

- OpenAI 회의 정리 요청에 용어 후보를 추가한다. 회의 텍스트의 근거에서 확인되지 않는 인식 표기는 버리고 후보만 회의별로 보관한다. 사용자가 범위와 표준 표기를 확인해 사전에 추가하기 전에는 인식 힌트나 교정에 반영하지 않는다.
- 구버전 정리에 용어 후보가 없는 경우 명시적 요청으로 별도 추출한다. 기존 요약과 메모를 변경하지 않는다.
- 검토 항목과 사용자 수정값을 회의별 로컬 파일에 저장한다. 검토한 내용은 새 정리 노트로 만들며 기존 노트를 덮어쓰지 않는다. 할 일을 회의 원문에 추가할 때는 명시적 동작을 요구한다.
- 일정은 편집 후 사용자가 저장한다. 같은 후보의 처리 상태를 먼저 기록해 응답 불명 시 자동 재시도하지 않고, 이전에 저장된 같은 제목 후보를 경고한다. 기존 버전이나 다른 앱에서 저장한 일정은 이 로컬 검토 기록에 없으므로 캘린더에서 직접 중복 확인이 필요하다.
- 종일 일정은 사용자가 선택하며, 마지막 표시 날짜는 포함하고 EventKit 종료일은 다음 날 0시로 전달한다.

## 검증 및 미완료

- `npm run check`: TypeScript 101개, Python 54개 통과. 합성 텍스트로 실제 OpenAI 연결·응답 스키마·상대 날짜 변환도 확인했다.
- Core Audio 도우미가 기본 마이크와 전체 시스템 또는 실행 중인 선택 프로세스의 소리를 같은 시간축에서 수집한다. 48kHz 입력을 필터링·혼합해 기존 16kHz 단일 WAV와 디스크 큐로 전달한다. 48kHz 기본 마이크만 지원하며, 다른 입력 설정은 오류로 중단한다. 선택 프로세스가 종료되거나 입력·기록에 실패하면 자동으로 마이크만 녹음하지 않는다.
- 알림음과 합성 한국어를 사용해 WAV, 앱 선택, 전사 및 Community-1 후처리 종료까지 시험했다. 실사용 회의·여러 앱 환경의 정확도는 미측정이다. 시스템 녹음 중 녹음 구간 재생을 막고 헤드폰 사용을 안내한다.
- 실제 Obsidian에서 녹음 소스 선택, AI 정리 검토, iCloud 일정 양식과 종일 선택을 확인했다. 설치된 플러그인의 시스템 오디오 무음 녹음·단일 WAV·Community-1 후처리도 성공했다. 테스트 일정을 Mac의 iCloud 캘린더에 저장해 캘린더 앱에서 확인한 후 삭제하고, 별도 EventKit 조회로 삭제를 확인했다. iCloud 서버와 다른 기기 간 동기화는 독립적으로 확인하지 않았다. 이후 시험은 스피커 출력 없이 진행한다.
