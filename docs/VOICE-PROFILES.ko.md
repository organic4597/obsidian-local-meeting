# 로컬 화자 음성 프로필

회의 시작 창에서 참여자의 동의를 확인하고 **회의 음성으로 프로필 자동 수집**을 켜면, 녹음 종료 후 Community-1이 단독 발언 그룹의 256차원 특징을 계산합니다. 별도 음성 녹음이나 발언 내용으로 프로필을 만들지 않습니다. 전사·기존 녹음과는 별도로 로컬에서 처리합니다. 설정은 다음 회의 시작 창에 유지하므로 회의마다 동의 여부를 확인하세요.

사용자가 그룹에 이름을 지정하면 조건에 맞는 특징이 그 이름의 새 프로필에 수집됩니다. 같은 이름의 기존 프로필이 있으면 자동으로 합치지 않으며, 음성 프로필 화면에서 직접 연결합니다. 향후 회의에서는 다른 회의에서 확인된 특징을 비교해 후보를 제시합니다. 모델 버전이 다르거나 같은 회의에서 나온 특징은 비교 기준으로 사용하지 않습니다. 그룹별로 최소 3초의 겹치지 않은 음성이 필요하지만 이 시간이 식별 정확도를 보장하지는 않습니다.

자동 이름 배정은 기본적으로 꺼져 있습니다. 실제 사용 환경에서 정답이 확인된 음성으로 유사도와 오배정률을 평가한 뒤 고급 설정에서 최소 유사도와 후보 간 차이를 둘 다 설정해야 합니다. 유사도는 확률이 아닙니다. 추가적인 최소 조건으로 현재 그룹에 단독 발언 10초, 기준 프로필에 다른 회의의 확인된 음성 60초, 비교 가능한 프로필 2개를 요구합니다. 이는 오배정을 줄이기 위한 설계상 조건이며 정확도 보증이나 검증된 임계값이 아닙니다. 이름을 자동 배정해 모은 특징은 사용자가 그룹을 확인하기 전까지 비교 기준으로 사용하지 않습니다.

음성 프로필 창에서 후보를 직접 연결하거나 기존 발언 검토에서 화자를 수정할 수 있습니다. 한 발언의 화자를 수정하면 해당 그룹이 오염되었을 가능성을 고려해 그 그룹에서 수집한 특징을 프로필에서 제외하고 충돌 상태로 표시합니다. 사용자가 편집한 노트 내용과 수동 화자 배정은 후처리 시 보존합니다. 자동 배정된 기존 노트의 이름은 프로필 삭제로 일괄 변경하지 않습니다.

프로필은 회의 저장 폴더의 `.local-meeting-quality/voice-profiles/`에 개별 JSON 파일로 저장하며, 프로필 파일 한 개의 총 크기는 메타데이터를 포함해 2,000,000바이트 이하입니다. 상한에 도달하면 새 특징은 저장하지 않고 기존 파일을 보존합니다. 세션의 `voice-features.json`은 해당 회의 그룹의 임시 비교 특징으로 별도 저장되며 이 한도에 포함되지 않습니다. 원본 WAV도 별도입니다. 프로필 삭제 시 그 프로필과 연결된 세션 특징을 함께 삭제하지만 기존 녹음·노트·화자 이름은 유지합니다. 아직 이름이 연결되지 않은 그룹의 세션 특징은 해당 회의 폴더에 남으므로 완전 삭제하려면 해당 파일도 삭제하세요. 특징은 민감한 생체정보로 취급하고 접근·백업을 관리하세요.

자동 수집을 켠 기존 회의라도 기능 도입 전에 처리되어 특징 파일이 없으면 자동으로 소급 생성되지 않습니다. 기존 회의에서 다시 처리할 수 있는지는 해당 회의의 원본 WAV와 처리 설정에 달려 있습니다.

검증 범위: 합성 음성으로 로컬 녹음 파이프라인과 Community-1/MPS 특징 생성, 저장 권한, 용량 제한, 중복 수집, 사용자 수정 시 특징 제외, 후보 검증 조건을 검사했습니다. 실제 화자 정답 자료가 없으므로 화자 식별 정확도와 오배정률은 측정하지 못했습니다.

## 연결 오류와 화자 번호

OpenAI 정리 창의 **회의 정리 만들기 / 다시 시도** 또는 **최신 내용으로 다시 정리**를 누르면 연결과 모델 목록을 다시 확인합니다. 모델 목록을 불러오는 중에도 버튼은 표시됩니다. 네트워크 복구 후 사용자가 다시 눌러야 하며, 회의 원문과 기존 정리 노트는 보존됩니다. 재시도 시 최신 회의 텍스트가 OpenAI로 전송됩니다.

회의 종료 후 같은 음성 그룹으로 분류되었지만 이름을 모르는 발언은 `화자 1`, `화자 2`처럼 구분합니다. 번호는 해당 회의에서 추정된 음성 그룹으로, 실제 인물이나 정확한 화자 구분을 보증하지 않습니다. 참여자 목록에서 이름을 바꾸거나 발언별로 수정할 수 있습니다. 구분 근거가 부족한 발언과 겹친 발언은 각각 미확정 또는 동시 발언으로 남습니다. 기존 회의는 로컬 회의록 상세 보기의 **기존 미확정 화자 번호 적용**을 눌러 저장된 음성 그룹에 번호를 부여할 수 있습니다. 직접 잠그거나 고친 발언과 충돌하는 그룹은 건드리지 않습니다.

## 참여자와 음성 그룹

회의에서 설정한 인원은 Community-1이 종료 후 구분할 화자 수의 상한 또는 고정값입니다. 참석자 이름을 자동으로 알아내지는 않습니다. 상세 보기의 참여자 영역에는 직접 등록한 이름과 아직 연결되지 않은 음성 그룹을 따로 표시하며, 모델 설정과 검출한 그룹 수를 확인할 수 있습니다. 미연결 그룹의 삭제·합치기 버튼에서 기존 참여자를 선택하면 발언 내용을 유지한 채 화자를 변경합니다. 이름만 삭제할 때는 연결 발언을 미확정으로 옮길 수도 있습니다. 직접 수정된 발언과 충돌하면 변경을 중단합니다.

녹음 중에는 참여자를 추가하고 **발언별 화자 수정**에서 이미 도착해 표시된 발언을 직접 지정할 수 있습니다. 지정한 이름은 임시 전사에 표시되고 종료 후에도 수동 배정을 보호합니다. 실시간 화자 자동 인식은 하지 않으며, 전사 처리 지연이 있을 수 있으므로 화면에 나온 발언을 확인하고 지정해야 합니다. 참여자 삭제와 그룹 합치기는 녹음 종료 후 가능합니다.

미연결 음성 그룹은 참여자 목록에서 **연결**을 누른 뒤 대상 이름을 직접 선택합니다. 삭제 대화상자도 발언을 옮길 대상을 명시적으로 선택해야 합니다. 삭제 과정에서 미확정으로 옮긴 그룹은 **삭제된 음성 그룹 복구**로 복원할 수 있으며, 삭제 이후 수정된 발언은 자동 복구하지 않습니다. 다른 노트에 복사된 회의록은 원본 변경과 자동 동기화되지 않으므로 **연결된 원본 회의록 열기**에서 확인하세요.
