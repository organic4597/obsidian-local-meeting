## 0.12.0 · AI 검토와 시스템 오디오

- Mac 기본 마이크와 전체 시스템 오디오 또는 현재 소리를 내는 선택 프로세스를 같은 회의의 단일 WAV와 전사 큐에 기록합니다. 캡처가 끊기거나 버퍼가 가득 차면 오류를 표시하고 원본을 보존합니다.
- 회의 정리 요청에서 용어 후보를 함께 추출합니다. 사용자가 확인해 추가한 용어만 로컬 사전의 인식 힌트에 적용합니다.
- 결정 사항·할 일·일정·확인 사항을 검토하고 수정·제외해 새 정리 노트를 만들 수 있습니다. 기존 노트와 사용자 수정은 덮어쓰지 않습니다.
- 일정을 검토하고 Mac 캘린더에 저장하며, 저장 결과가 불확실할 때 자동 재시도를 막습니다. 종일 일정은 사용자가 직접 선택합니다.
- 짧은 무음 구간에서 전사 큐가 진행되지 못하던 문제와 오디오 처리 초기화 시 버퍼가 찰 수 있는 문제를 수정했습니다.

### 검증 및 제한

TypeScript 101개, Python 54개 자동 검사 통과. 설치된 Obsidian에서 스피커 출력 없이 녹음 시작·종료, 단일 WAV 및 Community-1 후처리를 확인했습니다. 합성 텍스트로 OpenAI 연결과 상대 날짜 변환을 확인했습니다. 플러그인으로 테스트 일정을 iCloud 계정의 Mac 캘린더에 저장한 뒤 캘린더 앱에서 확인하고 삭제했으며, 별도 조회에서 삭제를 확인했습니다.

iCloud 서버 또는 다른 기기와의 동기화는 별도로 측정하지 않았습니다. 시스템 오디오 캡처는 macOS 15 이상, 48kHz 기본 마이크를 사용합니다. 선택 앱이 여러 프로세스로 오디오를 출력하는 경우 일부만 녹음될 수 있습니다. 장시간 회의, 실제 다화자 화자 정확도와 다른 마이크 형식은 추가 검증이 필요합니다. 다른 앱이나 이전 버전에서 만든 일정의 중복 여부는 캘린더에서 직접 확인해야 합니다.

### 설치 파일

`obsidian-local-meeting-v0.12.0-macos-arm64.zip`의 `local-meeting` 폴더를 Vault의 `.obsidian/plugins/`에 복사하고 커뮤니티 플러그인에서 활성화합니다. ZIP에는 플러그인과 macOS 보조 실행 파일만 포함되며 모델 가중치, Python 환경, 회의 녹음과 개인 설정은 포함되지 않습니다. 로컬 모델·Python 환경 준비와 경로 설정은 [설치 안내](https://github.com/organic4597/obsidian-local-meeting/tree/v0.12.0#설치와-개발)를 참고하세요.
