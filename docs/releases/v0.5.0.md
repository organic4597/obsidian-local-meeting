## 0.5.0 변경 이력 · 사전과 화자 처리 개선

- 개인·Vault·프로젝트·회의 사전: 표준 용어·발음·확인된 오인식, 범위별 우선순위와 비활성화, JSON 가져오기·JSON/CSV 내보내기
- 인식 전 로컬 ASR 문맥 힌트(최대 40항목·256토큰), 허용된 별칭 표기 통일과 교정 제안. 원문은 별도 보존
- 새 회의는 PCM 작업과 독립적으로 문맥을 유지하는 발언을 처리하고 최근 잠정 전사를 같은 ID의 개정으로 갱신
- 화자 활동 확률과 후보 ID를 보존하고 최근 10초의 화자 근거를 재평가. 불확실한 귀속을 강제하지 않음
- 발언 검토에서 원음 구간 재생·대사/화자 교정·직전 교정 취소·확인 완료. 직접 수정·삭제한 본문은 보호
- 실제 입력 장치·레벨·클리핑·입력 오류 진단, 개인정보·전사 본문을 제외한 진단 내보내기
- 정답 입력 양식과 로컬 CER·전사 화자 귀속 DER 평가 도구. 정답이 없는 자료는 점수를 계산하지 않음

첫 개선판은 [품질 설계서](docs/LOCAL-QUALITY-DESIGN.ko.md)의 P0~P1 범위다. 기존 회의는 자동 재전사하지 않으며 이전 큐 복구 경로를 유지한다. 0.5.0 당시 단어 정렬과 음성 표본 대조는 미구현이었다. 0.7.0은 미수정 대사의 로컬 단어 정렬을 추가했으며, 사용자 음성 표본 등록은 아직 지원하지 않는다.

사이드바의 **회의 사전**과 **발언 검토**, 오버레이 메뉴 또는 명령 팔레트에서 연다. 사전 변경은 현재 추론이 끝난 이후 발언부터 적용하며 과거 노트를 자동으로 바꾸지 않는다. 화자 활동의 퍼센트는 실제 사람의 신원 정확도가 아니다.

### 검증 및 한계

검증: TypeScript 46개와 Python 36개 통과. 실제 회의의 정답 CER·DER은 측정하지 못했다.
