## 0.10.0 · 요약 시간 범위에서 녹음 재생

요약의 `04:20–04:50` 같은 범위를 누르면 해당 회의의 로컬 녹음을 선택 구간만 바로 재생한다. 편집 화면·읽기 화면 모두 버튼으로 표시하며 Markdown 본문에는 링크나 관리용 문법을 추가하지 않는다. 편집 커서나 선택이 시간 범위 안에 있으면 원래 문자열을 그대로 편집할 수 있다. 구간 재생창에는 일시 정지·탐색·처음부터 다시 듣기·닫기를 제공한다.

한 번에 한 구간만 재생한다. 다른 구간을 누르거나 재생창을 닫거나 플러그인을 해제하면 이전 재생을 중지하고 버퍼를 해제한다. 녹음 중에는 헤드폰 확인 후 재생하며 새 녹음을 시작하면 열려 있는 구간 재생창을 닫는다. 긴 범위는 메모리 사용을 제한한 여러 버퍼로 이어서 재생하고 끝에서 멈춘다. 발언 검토의 기존 앞뒤 여유·30초 제한은 유지하고 요약 구간은 별도의 정확한 시작/종료 경계를 사용한다.

요약 파일과 회의 ID의 연결은 Vault별 로컬 색인에 저장한다. 현재 요약과 이후 생성하는 요약은 등록하며, 이전 해시 이름 요약은 해당 회의의 저장된 AI 결과 파일로 연결을 확인한다. 등록되지 않은 일반 노트의 시각은 자동 재생 버튼으로 바꾸지 않는다. 모델이나 API를 호출하지 않고, 원본 WAV와 노트 파일은 변경하지 않는다.
