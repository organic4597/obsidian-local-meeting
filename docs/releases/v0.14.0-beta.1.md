# 0.14.0-beta.1 · 선택 가능한 AI 정리 스킬

네 개의 오픈소스 스킬 지침을 회의록 API용으로 고정해 추가했습니다.

- summarize-meeting, stop-slop-ko, im-not-ai, K-Humanizer를 설정과 AI 정리 창에서 개별 활성화·비활성화. 초기값은 모두 켜짐.
- 선택한 지침을 기존 요약·할 일·일정·용어 요청 한 번에 결합. 모두 끄면 기본 정리 사용.
- 스킬 조합·원본 커밋·지침 버전을 결과와 캐시 식별에 포함. 변경 후에는 이전 결과와 구분해 새 노트 생성.
- 전사 원문·필기·수동 화자 지정과 편집한 정리 노트 보존. 저장 오류 시 토글 복원, 처리 중 설정 변경 차단.
- 원본 SKILL.md·참고 문서·MIT 고지·고정 커밋 및 파일 해시 동봉.

원본 스킬의 에이전트·셸 워크플로를 실행하지 않습니다. im-not-ai는 사실 보존과 윤문 지침을 적용하며 원본의 별도 진단·변경률 검사·품질 게이트는 포함하지 않습니다.

자동 검사 228개 통과. 16개 조합의 요청과 캐시 구분 및 편집 내용 보존을 검사했습니다. 실제 회의록을 API로 보내는 품질 비교는 수행하지 않았습니다.
