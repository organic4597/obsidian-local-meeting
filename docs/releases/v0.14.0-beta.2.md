# 0.14.0-beta.2 · 회의별 월-일-시 폴더

설정의 회의록 기본 폴더 아래에 새 회의마다 `MM-DD-HH/회의록.md`를 생성합니다. AI 정리·검토본도 같은 폴더에 모읍니다. 같은 시간의 회의는 `-2`, `-3`을 붙인 폴더로 구분합니다. 한국 시간의 시작 시각을 기준으로 하며 기존 회의는 이동하지 않습니다.

빈 탭에서도 새 회의를 시작할 수 있도록 시작 버튼의 활성화 조건과 안내를 수정했습니다. 폴더·문서 생성 전 준비 기록을 저장하고, 생성 응답이 불명확하면 중복 생성 대신 확인을 요청합니다. 녹음 WAV와 내부 처리 데이터는 기존 외부 오디오 저장소에 유지합니다.

beta.1의 네 AI 스킬은 실제 Obsidian 설정에서 모두 끈 상태의 재시작 유지와 AI 정리 창 표시를 확인했습니다. 현재는 모두 켜 두었습니다. 실제 회의 내용을 API로 전송하지 않았습니다.

자동 검사 233개(TypeScript 157, Python 76) 통과. 폴더 충돌·한국 시간 경계·시작 취소·실제 시작 흐름·설정의 명시적 꺼짐 유지·기존 필기와 수동 화자 보존을 포함합니다. 별도 GitHub 릴리즈를 발행하지 않은 개발판입니다.
