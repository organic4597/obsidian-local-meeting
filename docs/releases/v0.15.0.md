# 0.15.0 · 회의 화면 개편과 사전 오인식 방지

최신 개발판의 UI·저장 규칙과 사전 수정 사항을 정식 버전으로 통합했습니다.

- 회의·참여자·검토·도구 탭과 저장 위치·전사·AI·문제 해결 설정으로 화면 재구성. 고급 옵션과 AI 연결 설정은 별도 영역으로 분리.
- 지정 폴더의 `YYYY-MM-DD/MM-DD.md`에 새 회의록 생성. 상단에 시작 시각·시간대·참여 인원 설정·녹음 방식을 기록하고, 같은 날 추가 회의는 파일명에 번호를 붙임. AI 정리는 같은 날짜 폴더, WAV는 기존 위치 유지.
- 경로의 바로 아래 폴더만 표시하는 자동완성과 Tab 완성. 설치된 로컬 음성 엔진 자동 연결, 고급 경로 설정 분리.
- 사전 목록을 ASR decoder context로 주입하지 않아 반복 복창을 줄임. 저에너지 구간과 긴 용어 목록 출력의 보류 검사 추가. 사용자 확인된 별칭 교정은 유지.
- 필기 영역과 독립된 고정 높이의 실시간 전사 패널. 내부 스크롤·읽던 위치 유지·최신 발언 따라가기 제공.
- AI 용어의 기존 사전 항목 연결과 저장 상태·오류·재시도 수정. 기존 별칭·활성 상태·수동 교정 보존.
- 네 가지 AI 정리 지침(summarize-meeting, stop-slop-ko, im-not-ai, K-Humanizer)을 설정에서 개별 사용. 선택한 지침을 기존 한 번의 정리 요청에 결합하며 결과와 캐시를 구분.
- 화자 이름 저장 완료 전 성공 표시 방지, 저장 실패·편집기 준비 실패 처리 보강. 참여자·할 일 창 취소, 프로필 불러오기 재시도, 녹음 링크 문장 표시 개선.

정식 버전으로 다시 빌드·타입 검사 및 자동 검사 **251개(TypeScript 172, Python 79)**를 통과했습니다. npm audit의 알려진 취약점은 0개이며 ASR Python 의존성 충돌은 없었습니다. Astryx doctor는 실패가 없고 호스트 폰트 적용에 따른 폰트 확인 경고가 남습니다.

같은 코드의 최신 개발판은 Obsidian 1.15.1에서 주요 화면·키보드 탐색·폴더 목록·임시 입력 유지·취소·Mac 캘린더 읽기를 확인했습니다. 기존 원문·AI 정리·WAV·전사 JSON을 보존했습니다. 이번 정식 승격에서는 새 녹음·소리 재생·외부 AI 재요청·iCloud 서버 동기화 시험을 추가하지 않았습니다. 장시간 회의·화자 정확도·모든 테마의 호환성을 보증하는 검증은 아닙니다.

설치 파일은 **Apple Silicon macOS 15+ / Obsidian 1.11.4+**용 전체 ZIP입니다. ZIP의 `local-meeting` 내용을 `<Vault>/.obsidian/plugins/local-meeting/`에 설치하고 기존 `data.json`은 유지하세요. Python 실행환경과 모델 가중치는 별도 준비가 필요하며 설치된 엔진은 자동으로 연결합니다. 모델·녹음·개인 설정·토큰은 배포 파일에 포함하지 않았습니다.
