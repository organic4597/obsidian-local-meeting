## 0.7.0 · 텍스트 전사 → Community-1/MPS → OpenAI 정리

새 회의의 실시간 경로는 STT만 실행한다. `pending` 화자 표시는 노트에 쓰지 않는다. 2초 원음 큐와 단일 WAV 저장은 유지하며, 쉼 또는 최대 20초에서 대사를 확정한다. 이전 회의 복구는 원래 파이프라인을 유지한다.

회의 시작 창에서 0~32명의 화자 수와 적용 방식을 선택한다. **상한**은 Community-1의 `max_speakers`, **고정 인원**은 `num_speakers`로 전달한다. 상한 7명은 자동 검출이 6명이면 6명으로 남길 수 있으며, 고정 7명도 실제 사람별 정확한 분리의 보장은 아니다. 설정의 인원은 새 회의 시작 창의 기본값이고, 실제 선택값은 회의별 `pipeline.json`과 `meeting.json`에 보존한다.

회의 종료 후 ASR 자원을 해제하고 별도 Python 프로세스에서 로컬 Community-1/MPS를 실행한다. MPS를 사용할 수 없으면 CPU로 몰래 전환하지 않고 오류와 재시도 경로를 제공한다. 여러 화자가 걸친 미수정 발언은 로컬 Qwen3 ForcedAligner의 단어 시간으로 나누며, 원래 문자열과 문자 위치를 대조한다. 수정·삭제된 본문은 자동 분할하지 않는다. 원음과 원래 전사, 적용 전 스냅샷을 보존한다.

OpenAI 연결은 공식 **Sign in with ChatGPT** 공개 클라이언트 흐름이다. 시스템 브라우저, PKCE, state·nonce 검증, JWKS 서명/issuer/audience/만료 검증, 계정별 client ID, 갱신 토큰 회전, 로그아웃을 구현했다. 비밀 정보는 Obsidian SecretStorage에 저장하며 플러그인 data.json·회의 노트·로그에 넣지 않는다. 기존 Codex 인증 파일은 읽지 않는다. ChatGPT 사용 권한이 승인된 계정의 모델 목록을 표시하며 실제 모델 사용 권한은 완료된 요청으로 검증한다. 계정·요금제·지역·사용량 제한은 OpenAI가 판단한다. API 키가 필요한 별도의 결제 경로는 이 버전에 구현하지 않았다.

화자 구분 완료 후 최신 문서와 사용자 필기, 발언 ID를 OpenAI Responses API로 보내 요약·결정·할 일·일정 후보·확인 사항을 정리한다. 오디오는 보내지 않는다. OAuth 요청 계약에 따라 `store:false`, `stream:true`를 사용한다. 완료 이벤트와 출력 형식·근거 ID를 검증한 결과만 저장한다. 정리 노트는 원문 옆의 별도 파일이며, 기존 정리 노트를 덮어쓰지 않는다. 처리 중 원문 변경이 있으면 이전 스냅샷 기준임을 표시한다. 일정 후보는 편집 가능한 캘린더 저장 화면을 거쳐 등록한다.

설치 환경: 기존 MLX Python에 `worker/requirements.txt`, 분리한 Community Python에 `worker/requirements-community.txt`를 설치한다. Community-1 공식 이용 조건에 동의하고 모델을 로컬에 내려받은 후 설정에서 경로를 지정한다. 정렬 모델은 `mlx-community/Qwen3-ForcedAligner-0.6B-4bit` 로컬 폴더를 사용한다. 설치자가 플러그인 폴더의 `local-runtime.json`에 `communityPython`, `communityModel`, `alignerModel` 절대 경로를 기록하면 비어 있는 설정의 초기값으로 읽는다. 이 파일에는 토큰을 저장하지 않는다.
