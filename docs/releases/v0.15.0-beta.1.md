# 0.15.0-beta.1

- 새 회의는 지정 폴더의 `YYYY-MM-DD/MM-DD.md`로 생성. 같은 날의 추가 회의는 파일명 번호로 구분하며 시작 시각·인원 설정·녹음 방식을 맨 위에 기록.
- 상세 보기, 설정, AI 검토를 Astryx 탐색 탭으로 재구성. 고급 옵션·복구·AI 연결 설정은 별도 탭 또는 접힌 영역으로 이동.
- 상세 표시와 오버레이 겹침 방지, 키보드 탐색과 선택 표시 보강. 기존 필기·음성 저장 경로·화자 교정 유지.
- 이름 저장의 거짓 성공 및 편집기 준비 실패 처리 수정. 참여자 추가·삭제/연결·할 일 취소, 프로필 불러오기 재시도 추가.
- 녹음 링크의 편집기 표시 우선순위 보강. 기존 문서와 음성 파일은 일괄 변환하지 않음.
- 빌드·타입·자동 검사 251개 통과, Astryx doctor 실패 없음. 실제 Obsidian에서 주요 화면·취소·읽기·탭·임시 입력 보존 확인. 신규 마이크 녹음·소리 재생·외부 AI 재요청·실제 일정 쓰기는 수행하지 않음.
