# 0.14.0-beta.3 · 저장 폴더 자동완성

회의록 기본 폴더, 회의 시작 창, 이전 회의의 정리 폴더에서 기존 Vault 폴더를 목록으로 고를 수 있습니다. 입력칸을 클릭하거나 펼침 버튼으로 목록을 열고 경로 일부를 입력해 검색합니다. 클릭·방향키·Enter 선택과 Escape 닫기를 지원합니다. 새 경로의 직접 입력도 유지하며 회의 시작 전에는 폴더를 생성하지 않습니다.

Obsidian의 기본 제안 팝업을 사용하고 매 검색마다 최신 Vault 폴더를 조회합니다. 한국어 정규화·대소문자를 구분하지 않고 검색하되 실제 경로는 보존합니다. 숨김 폴더와 유효하지 않은 경로는 후보에서 제외합니다. 설정이나 시작 창을 닫으면 제안 팝업도 닫습니다.

기존 월-일-시 폴더 구성과 회의록·AI 정리 연결을 유지하며 녹음 WAV·큐·DB의 외부 저장 위치는 변경하지 않습니다. 기존 자동 검사 233개(TypeScript 157, Python 76)가 통과했습니다. 별도 GitHub 릴리즈를 발행하지 않은 개발판입니다.
