# 0.14.0-beta.5 · 경로 단계별 완성

회의록 저장 경로 선택을 셸의 경로 완성처럼 바꿨습니다. Vault의 모든 하위 경로를 펼치는 대신 현재 경로의 바로 아래 폴더만 표시합니다. `06-기록/회`를 입력하면 그 위치에서 `회`로 시작하는 폴더로 좁혀집니다. Tab은 유일한 후보 또는 공통 접두사까지 완성하고, 클릭으로 폴더 안에 내려갑니다. 방향키·Enter 선택과 Escape 닫기도 지원합니다. 새 경로를 직접 입력할 수 있습니다.

별도 설정 창에서도 입력칸과 같은 문서에 속한 드롭다운을 사용합니다. 목록을 여는 것만으로 설정값을 선택·변경하지 않습니다. 한글 조합 중 Enter를 가로채지 않고, 제안 항목 이동 때문에 전체 설정 화면이 스크롤되지 않도록 했습니다.

자동 검사 241개(TypeScript 165, Python 76) 통과. 단계별 탐색·이름 접두사·공통 경로 완성·존재하지 않는 새 경로 유지·한글 정규화와 기존 파일 보존 검사를 포함합니다. 새 녹음이나 AI 요청은 실행하지 않았습니다.

[저장 폴더 안내](../STORAGE-RETRY.ko.md), [로컬 엔진 자동 연결](../LOCAL-RUNTIME.ko.md)

Obsidian 1.15.0 실제 설정 창에서 최상위 폴더만 표시, 클릭으로 한 단계 이동, 접두사 필터, Tab 완성과 방향키·Enter 선택을 확인했습니다. 회의 시작 창에도 저장 경로가 전달되며 동일한 Tab 완성이 동작했습니다. 시작은 취소하여 새 회의나 녹음을 만들지 않았습니다. 임시로 바뀐 두 경로 설정은 검사 전 값으로 복구했고 기존 원문·AI 정리·WAV의 SHA-256이 동일했습니다.
