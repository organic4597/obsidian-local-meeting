# 0.13.0 · 스트리밍 전사와 안전한 회의 복구

회의 중 전사·필기·화자 수정을 함께 유지하고, 종료 후 처리 실패를 단계별로 이어갈 수 있도록 개선했습니다.

- 문맥을 유지하는 로컬 스트리밍 전사, 말끝 확정, 필기 시점 연결과 수동 수정 보호.
- 선택 가능한 실시간 잠정 화자 구분과 종료 후 Community-1/MPS 재분석. 인물별 발언 요약과 문장 클릭 녹음 재생.
- 동의 후 회의 음성 특징을 모으는 로컬 화자 프로필, 사용자 이름 연결·오배정 수정과 파일당 2MB 제한. 자동 이름 배정은 기본 꺼짐.
- 반복 오인식 사전 후보와 의심 구간 종료 후 재전사 후보. 사용자 확인 없이 원문이나 사전을 대체하지 않음.
- 지정 폴더에 한국 시간 시작일 기준 `YYYY-MM-DD/회의록.md` 자동 생성. 같은 날 회의는 순번으로 구분.
- 기본 오디오 저장 폴더 변경과 노트·폴더 이름 변경 후 기존 녹음 연결 유지. 이동 연결 시 원음과 최신 교정 상태 확인.
- 단계별 상태·실패 재시도, 검증된 완료 결과 재사용, 부분 재전사·정렬 이어서 처리.
- 정리 노트 생성 영수증으로 중복 생성 방지. 오프라인에서도 저장된 AI 결과 반영 재시도, 직접 편집한 노트 보존.
- 불확실한 녹음 이동 연결 차단, 손상된 캐시 재계산, 강제 종료에도 해제되는 Python 실행 잠금.

자동 검사 **221개 통과**, npm 알려진 취약점 0개, Python 의존성 충돌 0개. 실회의 표본으로 만든 120초 큐 부하·완료 결과 3회 재사용·캐시 손상·프로세스 강제 종료·WAV 헤더 복구를 무음 검증했고 원음 보존을 확인했습니다.

설치 파일은 **Apple Silicon macOS 15+**용 전체 ZIP입니다. ZIP 안의 `local-meeting` 내용을 `<Vault>/.obsidian/plugins/local-meeting/`에 설치하며 기존 `data.json`은 유지하세요. Python 환경과 모델 가중치는 별도 준비가 필요합니다. 자세한 내용은 ZIP의 `INSTALL.ko.md`를 참고하세요.

실제 화자 정확도와 수 시간 실회의·절전·장시간 시스템 오디오 호환성을 보증하는 릴리즈는 아닙니다. 실시간 화자 구분은 잠정 결과이며 최종 원음 확인과 수동 수정이 가능합니다. 이번 검증에는 새 AI API 요청이나 iCloud 서버 동기화 시험을 포함하지 않았습니다.
