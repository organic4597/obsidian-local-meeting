## 0.9.0 · 간결한 검토·일정·요약

- 오버레이는 준비/녹음 중/정리 중/완료만 표시한다. `검토 99+`를 제거하고 빈 대기 수치는 숨긴다. 같은 오류 알림은 1분 안에 반복하지 않는다.
- 검토 항목을 종류별로 접어서 표시하고 선택적으로 펼친다. 기존 참여자는 유지하며 연결되지 않은 음성 군집은 참여자로 자동 추가하지 않는다. 발언 검토에서 기존 참여자에 연결하거나 이름을 입력해 추가한다. 처음 분석하는 회의의 익명 화자 번호는 구분용이며 신원 인증이 아니다.
- 일정 후보는 회의 시작일과 Asia/Seoul 기준으로 날짜를 반환한다. `내일`, `모레`, `다음 주 월요일`을 실제 날짜로 계산하고 로컬에서 검증한다. 날짜와 시각을 분리해 미정 시각을 만들지 않는다. 여러 독립 날짜는 별도 후보로, 명시한 범위는 시작/종료 날짜로 보존한다. 날짜를 특정할 수 없는 ‘다음 주’는 날짜 확인 대상으로 남긴다.
- AI 요약은 `근거:`와 개별 시각 나열 대신 실제 발언 시작–종료 범위를 표시한다. 가까운 구간은 합치고 멀리 떨어진 구간은 분리한다. 확정되지 않은 담당자/기한 반복과 모델·해시가 드러나는 파일명을 줄인다. 원본 근거 ID는 로컬 구조화 결과에 유지한다.
- 기존 요약은 ‘간결한 형식으로 새 노트 만들기’로 별도 보기를 만들 수 있다. 기존 노트와 수정 사항은 덮어쓰지 않는다. 날짜만 확정된 일정은 캘린더 입력창에서 날짜를 미리 채우고 시각은 빈칸으로 둔다. 저장 버튼을 누르기 전에는 캘린더를 변경하지 않는다.

### 검증 및 한계

검증: TypeScript 90개와 Python 45개 통과. 설치된 앱과 합성 문장의 OpenAI 상대 날짜 처리, 캘린더 초안 화면을 확인했다.
