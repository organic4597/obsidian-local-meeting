# 0.13.0-beta.6

날짜별 새 회의록 생성과 저장 위치 연결, 단계별 후처리 재시도를 추가한 시험 버전입니다.

- 지정한 Vault 폴더 아래 한국 시간 시작일의 `YYYY-MM-DD/회의록.md` 생성. 같은 날 제목 충돌은 순번으로 구분하고, 취소 시 생성하지 않음.
- 새 회의의 기본 저장 폴더와 과거 세션 연결, 공통 사전·음성 프로필 위치 분리.
- 노트와 폴더 이름 변경 후 원문·정리 노트의 녹음 연결 유지. 이동 세션은 ID·교정 메타데이터·WAV 내용 확인 후 연결.
- 전사 마감·재전사 후보·화자 분석·시간 정렬·본문 반영·AI 정리·정리 노트 생성 상태 화면과 이어서 처리.
- 원음·모델 가중치·설정·처리 코드·산출물 해시를 검사해 완료 결과 재사용. 부분 재전사와 시간 정렬은 남은 구간부터 실행.
- 모델의 새 결과는 별도 시도 폴더에 저장. 완료 회의 재시도 시 STT 로딩과 원본 WAV·전사·큐 DB 변경 방지.
- AI 결과 저장과 문서 생성 분리. 문서 생성 직후 중단에도 같은 노트 재사용하고 직접 수정한 정리 노트 보존.
- 같은 화자 분석의 시간 정렬만 개선된 재시도도 반영하고, 기존 음성 그룹 번호와 사용자 화자 수정 유지.
- 원자적 상태 저장·백업·실행 잠금과 새 회의록 생성 준비 기록 추가.

자동 검사 217개 통과. 실제 회의 녹음 24초의 별도 복사본으로 무음 공급→전사→재전사 후보→Community-1/MPS→시간 정렬과 캐시 재시도를 검증했습니다. 재시도 전후 원본 WAV·전사·큐 DB·파이프라인 설정의 해시가 같았습니다. Obsidian에서 새 시작 창, 잘못된 경로 차단, 취소 시 미생성, 기존 회의 위치 목록과 처리 상태 화면을 확인했습니다.

이번 검증에서는 새 AI API 요청이나 캘린더 등록을 실행하지 않았습니다. 장시간 부하·네트워크 파일 시스템·여러 장치 간 교정 병합은 검증 범위가 아닙니다.
