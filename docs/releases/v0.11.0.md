## 0.11.0 · Community-1 전용 화자 구분

- 기존 Nemotron 3 화자 모델 경로와 NeMo-Speech 실행 코드·설정·설치 스크립트를 제거했다. 새 회의는 로컬 Qwen STT와 종료 후 Community-1/MPS 화자 구분을 사용한다.
- 완료된 이전 형식 회의는 기존 전사와 이름을 보존하며 Community-1으로 재분석할 수 있다. 미완료 큐, 오디오 누락 또는 확인되지 않은 조각이 있으면 자동 복구를 중단하고 원본을 보존한다.
- 플러그인은 인원을 지정하지 않거나 1~32명을 상한·고정 인원으로 설정할 수 있다. 설정값이 실제 화자 분리 정확도를 보장하지는 않는다.
- 이 Mac의 프로젝트 모델 사본과 모델 캐시 사본, 프로젝트 전용 NeMo-Speech 런타임을 휴지통으로 이동했다. Community 모델·회의 녹음은 유지한다.

### 검증 및 한계

TypeScript 94개와 Python 49개 자동 검사 통과. 한국어 합성 음성으로 Qwen STT와 Community-1/MPS 후처리를 확인했고, Obsidian 1.14.5에서 플러그인 활성화 및 설정 화면을 확인했다. 기존 요약의 시간 범위를 편집·읽기 화면에서 클릭해 재생 상태를 확인했다. 실제 다인 회의의 화자 정확도를 측정한 것은 아니다.
