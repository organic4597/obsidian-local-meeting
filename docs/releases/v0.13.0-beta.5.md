# 0.13.0-beta.5

P1 안정화와 오인식 검토 기능을 추가한 시험 버전입니다.

- 캡처 정지 오류에도 복구 체크포인트와 후속 자원 정리 시도.
- 잠정 발언은 화자만 수정하고, 대사는 말끝 이후 교정. 화자 지정으로 후속 전사가 잠기는 문제 수정.
- 이전 버전의 잠정 교정은 증명 가능한 새 꼬리를 보존하고 충돌은 검토 후보로 유지.
- 외부 수정 후 필기 시간 연결 재계산, 잠정 군집 번호와 최종 인원 상한 분리.
- 실시간 미리보기 선형 생성과 자동 메타데이터 저장 묶음 처리.
- 반복된 사용자 교정에서 사전 후보 수집. 사용자 확인 뒤 기존 사전 편집기로 등록.
- 종료 후 의심 구간의 동일 범위 및 전후 문맥 재전사 후보 생성. 원문·필기·화자를 자동 변경하지 않음.
- 발언별 수동 재전사와 최종 분할 발언 지원, 이전 잠정 검토 사유 정리.

자동 검사 200개 통과. 실제 회의 녹음 32초의 별도 복사본으로 무음 실시간 공급, 재전사 후보 2개, 종료 후 화자 분석까지 확인했습니다. 정확도 향상률과 장시간 p95는 측정하지 않았습니다. 저장 루트 변경/노트 이동 후 과거 녹음 연결(F06)은 후속 개선 대상입니다.
