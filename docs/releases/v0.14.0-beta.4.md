# 0.14.0-beta.4 · 로컬 엔진 자동 연결

일반 설정의 Python·모델 경로 입력을 제거하고 연결 상태와 자동 재연결 버튼으로 바꿨습니다. 수동 경로, 테스트 WAV, 입력 장치 번호와 프로필의 고급 임곗값은 별도 문제 해결 창에서만 표시합니다.

설치 정보와 이 Mac의 공용 연결 정보, 정해진 설치 구조와 Community 로컬 캐시를 탐색합니다. 유효한 기존 설정을 유지하고 빠진 경로만 보완하며, 다른 Vault에서도 설치를 재사용합니다. 기존 녹음·회의록·필기·화자 수정과 오디오 저장 위치는 유지합니다. 새 설치의 빈 오디오 위치에는 사용자 앱 데이터 폴더를 기본값으로 사용합니다.

자동 검사 238개 통과. 실제 Mac에서 기존 환경과 새 Vault의 자동 탐색 및 ASR/Metal·Community/MPS 의존 패키지 확인을 수행했습니다. 후속 beta.5 화면 검사에서 자동 연결·재연결과 일반 화면의 경로 숨김 및 고급 창 표시를 확인했습니다. 모델·Python 패키지 자동 다운로드 설치는 포함하지 않으며 첫 환경 준비와 Community 모델 조건 동의는 여전히 필요합니다.
