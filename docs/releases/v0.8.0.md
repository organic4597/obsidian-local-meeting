## 0.8.0 · 고스트 전사와 자연스러운 글자 표시

새 회의의 실시간 전사는 노트 하단의 흐린 고스트 텍스트로 나타난다. 편집기 장식으로 표시하며 Markdown 본문·커서·실행 취소 이력을 변경하지 않는다. 전사와 교정은 회의별 로컬 데이터에 계속 저장하고, 회의를 복구하거나 노트를 다시 열면 미리보기를 복원한다. 고스트 대사를 수정하려면 발언 검토를 사용하고 본문에는 필기를 자유롭게 입력한다. 읽기 모드에서는 장식을 표시하지 않으므로 편집 모드에서 확인한다.

종료 후 Community-1/MPS와 단어 정렬이 끝나면 화자별 확정 대화를 일반 글자 색으로 이어서 보여주고 본문에 저장한다. 글자 표시만 애니메이션으로 처리하므로 매 글자마다 파일을 쓰거나 STT를 다시 호출하지 않는다. 긴 실시간 업데이트는 최대 약 1.2초, 확정 기록은 최대 약 8초로 표시 시간을 제한하며, 시스템의 동작 줄이기를 사용하거나 노트가 닫혀 있으면 즉시 저장한다. 실제 ASR 결과는 발언 종료 또는 최대 문맥 길이 이후 도착하며, 이 효과가 음성 인식 자체를 글자 단위 스트리밍으로 바꾸지는 않는다.

확정 전 계획을 먼저 저장해 중단 후 이미 기록된 본문을 중복 삽입하지 않는다. 복구 시 본문이 계획과 다르면 임시 전사를 보존하고 확인을 안내한다. 후처리 오류 시에도 명령 팔레트 또는 오버레이의 **임시 전사를 본문으로 확정**으로 전사만 저장할 수 있다. 기존 회의와 직접 수정한 본문은 이 표시 방식으로 변환하지 않는다. AI 요약·할 일·일정은 기존처럼 별도 정리 노트를 사용한다.
