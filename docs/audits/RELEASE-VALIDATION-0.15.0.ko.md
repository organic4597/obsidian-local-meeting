# 0.15.0 릴리즈 검증

2026-11-13 · Apple Silicon macOS · Obsidian 1.15.1의 최신 개발판 UI 확인과 정식 승격 검사를 구분한다.

## 정식 승격에서 실행한 검사

- 정식 버전 0.15.0으로 manifest·package·lock 버전을 일치시키고 `npm run check` 재실행: 빌드·타입 검사, TypeScript 172개, Python 79개 모두 통과. 실패 0개.
- `npm audit`: 알려진 취약점 전체 0개. 설치된 ASR Python 환경의 `pip check`: 충돌 없음. 새 PC의 Python 환경까지 검증했다는 의미는 아니다.
- `npx astryx doctor --built dist --json`: 실패 0개. Neutral 테마 Figtree 폰트 확인 경고는 이전 개발판과 같다. 공개 CSS를 탐색 영역에 한정해 조립하고 호스트 폰트를 사용하며 원격 폰트 @import는 포함하지 않는다. 웹사이트용 Taste gate는 적용 대상이 아니므로 실행하지 않았다.
- 시스템 오디오 도우미의 ad-hoc 코드 서명 무결성 확인. 두 native 실행 파일 모두 arm64. 캘린더 도우미 요구사항 때문에 전체 설치 ZIP은 macOS 15+ 대상.
- 배포는 빌드 산출물과 명시한 문서·라이선스만 별도 폴더에 복사한다. Python 환경·모델·녹음·개인 설정·토큰·로컬 실행환경 연결 정보·소스맵은 제외한다. ZIP 경로·필수 파일·실행 권한·빌드 파일 해시를 검사하고 SHA-256 목록을 제공한다.

기능 코드는 ed3212e의 최신 반영본과 같다. 정식 승격에서 기능을 추가하거나 사용자 자료를 일괄 변경하지 않았다. 자세한 자동 검사 범위는 [UI 검증 기록](../ux-overhaul/VERIFICATION.ko.md), 이전 복창 회귀 표본은 [사전 복창 방지](../ASR-ECHO-FIX.ko.md)를 참고한다.

## 직전 실제 화면 확인

같은 코드의 0.15.0-beta.1 설치본에서 상세/설정/새 회의/AI 검토/캘린더를 확인했다. 탭 클릭·좌우 방향키·Home/End, 자식 폴더 목록, 검토 탭 사이 임시 입력 보존, 빈 이름 차단, 삭제 대상 미선택 차단, 작성 취소, 연동 공휴일 읽기를 확인했다. 녹음 링크 문장의 재활성화 직후 표시와 시간 툴팁도 확인했다. 원문·AI 노트·WAV·전사 JSON 해시는 동일했다. 설정 보존의 시점과 범위는 위 UI 검증 기록을 따른다.

## 수행하지 않은 항목

정식 승격 중 새 실마이크/시스템 오디오 녹음·소리 재생·외부 AI 추론·실제 일정 쓰기는 실행하지 않았다. iCloud 서버 동기화, 수 시간 회의·절전·모든 테마·화면 읽기 프로그램의 전체 접근성, 실제 화자 정확도 평가는 이번 결과에 포함하지 않는다. 침묵 검사는 에너지 기준이며 모든 배경 소음이나 아주 약한 발화를 정확히 구분하지 못한다. 기존에 삽입된 오인식 문장은 자동 삭제하지 않는다.
