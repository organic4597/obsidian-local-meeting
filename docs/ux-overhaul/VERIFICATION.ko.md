# UI/UX 검증 기록 · 0.15.0-beta.1

2026-11-13 · macOS/M4 · Obsidian 1.15.1 · CUA 실제 설치 화면 + 격리 자동 검사.

## 자동 검사

`npm run check` 통과: TypeScript 172개 + Python 79개 = **251개**, 실패 0개. 빌드와 타입 검사 통과. 신규 검사는 날짜 경계·같은 날 중복 이름·헤더 옵션·기존 문서 보존, 화자 이름 저장의 완료 대기·실패 반환·롤백·재시도, 편집기 준비 실패 시 거짓 성공 방지를 포함한다. 기존 실제 시작 흐름은 가상 Vault와 녹음 실행 대역을 사용해 문서가 준비된 뒤 실행기가 시작되는지 검사한다. 테스트가 실제 마이크를 켜지 않는다.

기존 검사는 동시 필기·화자 수정 보호, 단계별 재시도·저장 영수증·위치 연결, 사전 중복 연결과 실패 재시도, AI 일정 검토·상대 날짜·중복 방지, 음성 프로필 보호, 스트리밍·침묵·사전 복창 방지를 포함한다. ‘251개’는 모든 버튼을 실제 서비스와 251번 누른 횟수가 아니다.

`npx astryx doctor --built dist --json` 실패 없음. 테마 폰트 확인은 경고다. 생성된 Neutral 테마 모듈이 Figtree font import를 선언하지만 번들에서는 CSS import를 무시하고 필요한 공개 CSS만 조립하며 fonts.css는 넣지 않는다. 최종 CSS에 원격 @import가 없고 호스트 폰트 토큰으로 연결했다. doctor의 번들/JSX 순수성 검사는 정보 수준이며 실제 Obsidian 화면 검증을 대신하지 않는다. Taste의 웹사이트 gate는 미실행이다.

## 화면 근거와 보존

개편 전 5화면과 개편 후 화면을 `/tmp/lm-ux-audit-2026-11-13`에 저장하고 직접 확인했다. 캡처에는 실제 회의 내용이 있어 GitHub에 올리지 않는다. 설정·AI 검토·시작 창·사이드바·달력을 확인했고, 실제 검토 탭에서 임시 문장을 입력한 뒤 다른 탭을 거쳐도 남아 있음을 확인했다. 저장 버튼은 누르지 않고 원래 문장을 복구·종료했다.

원문 노트·AI 정리 노트·WAV·전사 JSON의 SHA-256은 최종 확인까지 일치했다. 설정도 중간 검증 체크포인트에서 모든 키가 동일했다. 최종 화면 확인 시 이전 회의 정리 폴더(summaryFolder)는 다른 값으로 변경된 상태여서 현재 값을 유지했으며 변경 원인을 단정하지 않았다. 신규 문서 생성과 수동 화자 변경은 격리 검사로 확인했다. 실제 개인정보를 GitHub 테스트 자료나 새 AI 요청으로 전송하지 않았다.

## 남은 범위

전체 장시간 회의의 실시간 UX·실마이크·시스템 오디오·외부 AI 장애·iCloud 서버 동기화는 이번 UI 개편에서 다시 시험하지 않았다. 다른 Obsidian 테마·저해상도·화면 읽기 프로그램의 전체 접근성 시험도 완료로 표시하지 않는다. 선택 색은 호스트 테마를 따른다. AI가 담당자에 내부 화자 ID를 반환한 과거 결과는 기존 데이터를 유지하며, 이번 변경으로 임의의 이름으로 정정하지 않는다.

편집 보기에서 처음 열린 일부 녹음 문장이 잠시 빈 줄처럼 보였고 이후 화면 재구성으로 나타나는 현상을 관찰했다. 녹음 링크 장식의 우선순위를 높여 호스트 장식과의 충돌을 줄였으며, 최종 재활성화 직후 실제 문장과 시간 툴팁이 표시되는 것을 확인했다. 이는 [CodeMirror 장식 우선순위](https://codemirror.net/docs/ref/#view.EditorView%5Edecorations)에 근거한 조정이며 모든 테마·타 플러그인의 충돌이 해결됐다는 의미는 아니다. 원문 파일을 바꾸는 수정이 아니다.
