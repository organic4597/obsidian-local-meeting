# Local Meeting UI/UX 개편 · 2026-11-13

대상: 기존 Obsidian 데스크톱 플러그인. 마케팅 웹사이트가 아닌 회의 기록 도구.

사용자 요청: 모든 화면·옵션·버튼·기능 점검과 전면 개편. Meta Astryx와 Taste 적용. 새 회의는 YYYY-MM-DD/MM-DD.md, 문서 맨 위에 시작 시각과 기타 회의 정보. 기존 회의/녹음/수동 교정은 보존.

## 적용한 스킬과 범위

- Meta 공식 meta/astryx의 astryx 스킬 설치. CLI/Core/Neutral 0.7.15, React 19. CLI search/build/component/theme/layout/migration 문서를 읽고 기존 페이지 보존·단계적 마이그레이션 지침 적용. 생성된 AGENTS.md를 준수한다.
- Leonxlnx/taste-skill의 design-taste-frontend 2.5.1 설치. 화면은 하나의 정보 위계, 일관된 간격/타이포/컨트롤, 명확한 한국어 동작명, 줄바꿈/좁은 폭/키보드/저동작 검사 원칙을 적용. 현재 배포본은 웹사이트 중심이므로 영웅 영역·사진·셰이더·스크롤 연출과 웹사이트 gate는 네이티브 Obsidian 화면에 적용하지 않는다. gate 통과를 주장하지 않는다. 다른 UI 자동화 스크립트는 사용하지 않는다.
- Product Design audit 지침으로 현재 화면을 먼저 캡처하고 관찰했다. 캡처 도구는 CUA native Obsidian, 저장 위치는 /tmp/lm-ux-audit-2026-11-13. 캡처는 로컬에만 보관하고 회의 내용을 외부 업로드하지 않는다.

## 구현 및 검증 순서

1. 날짜 규칙과 헤더, 경로 충돌·응답 유실·사용자 필기 보존 검사.
2. Astryx 기반 탐색과 테마 격리. Obsidian 전체에 reset/theme CSS를 적용하지 않는다. 폰트 원격 다운로드를 하지 않고 호스트 폰트 사용.
3. 사이드바/설정/새 회의/AI 검토 구성 개편. 사전·프로필·검토·캘린더는 기능을 유지하며 동일한 컨트롤 위계 적용.
4. 버튼 행렬 작성: 목적/활성 조건/로딩/완료/실패/재시도/초안 보존/부작용. 신규 버그 수정과 자동 검사.
5. 빌드/기존 전체 검사/doctor와 실제 화면의 폭·키보드·스크롤·팝업 점검. 실 녹음/AI 외부 전송/사용자 일정의 임의 변경은 하지 않는다. 테스트 원본 해시와 설정 보존을 확인한다.
6. 설치와 문서, GitHub 개발 브랜치 업로드. 검증하지 못한 항목은 명시하고 ‘모든 실제 환경에서 검증’이라고 주장하지 않는다.

구현·설치·주요 화면 검증 완료. 자동 검사 251개 통과. 결과와 한계는 VERIFICATION.ko.md에 기록했다. 정식 릴리즈는 발행하지 않음.
