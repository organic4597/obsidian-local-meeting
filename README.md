# Obsidian Local Meeting

Apple Silicon Mac용 로컬 한국어 회의록 플러그인. 외부 AI 추론 API 없이 녹음·전사·자동 화자 구분을 수행합니다.

## 0.2.0 구현 기능

- 녹음과 추론을 분리한 PCM WAV + SQLite 디스크 큐, 중지 후 남은 작업 처리와 복구
- 한국어 미세조정 Qwen3-ASR-1.7B MLX 8비트 / 혼합 4비트 지원
- **Nemotron 3 Diarization** 로컬 스트리밍 모델 연결, 최대 8개 익명 화자, 같은 회의 안에서 화자 상태 유지
- 화자 발언 경계에 맞춰 오디오를 잘라 STT에 전달. 겹친 발언은 ‘동시 발언’으로 표시
- 노트 본문에는 **`화자: 대사`**만 기록. 식별자·HTML 주석·자동 굵게 문법을 본문에 넣지 않음
- 현재 회의의 시간 표시 버튼/단축키. 표시를 켜면 `(00:00:05) 화자 2: 대사` 형태
- 사용자가 직접 적은 필기와 수정한 문장은 보호. 원본 매핑과 시간은 Vault 외부의 세션 JSON에 보관
- 오른쪽 상단 반투명 마이크 아이콘: 녹음 중에는 빨간 상태 표시, 클릭하면 작은 제어 메뉴
- 사이드바는 상세 보기. 최소화해도 녹음과 전사는 계속됨
- macOS EventKit을 통해 **iCloud 캘린더 선택·향후 일정 조회·일정 생성/갱신**. Apple ID나 앱 전용 암호를 플러그인에 저장하지 않음
- 현재 노트에 기한이 있는 할 일 체크박스 추가

| 기본 단축키 | 동작 |
| --- | --- |
| `⌘⇧M` | 녹음 시작 / 중지 |
| `⌘⌥M` | 상세 보기 / 최소화 |
| `⌘⌥T` | 현재 회의 시간 표시 켜기 / 끄기 |

Obsidian 설정 → 단축키에서 변경할 수 있습니다.

자동 화자 ID는 실제 이름이 아닙니다. 상세 보기에서 이름을 지정하고 오귀속을 고칠 수 있습니다. 모델을 연결하기 전에 만든 기록은 자동으로 다시 전사하지 않습니다.

## 설치와 개발

Apple Silicon macOS 15+, Python 3.11, Node.js 22+, Swift 컴파일러가 필요합니다.

```sh
npm ci
python3 -m venv .venv
.venv/bin/pip install -r worker/requirements.txt
npm run check
```

Mac에서 빌드하면 EventKit 보조 실행 파일도 컴파일합니다. `dist/` 내용 전체를 `<Vault>/.obsidian/plugins/local-meeting/`에 복사하고 커뮤니티 플러그인에서 Local Meeting을 활성화합니다.

설정에 Python 실행 파일, 로컬 ASR 모델 폴더, Vault 외부 녹음 저장 폴더, 화자 GGUF 모델 파일과 NeMo C 라이브러리 경로를 지정합니다. 회의 중에는 모델을 자동 다운로드하지 않습니다.

### ASR 모델 준비

`TeamUNIVA/qwen3_asr_1.7b_ko` 원본 체크포인트를 미리 내려받은 뒤 변환합니다. 변환은 로컬 파일만 읽습니다.

```sh
.venv/bin/python scripts/prepare_model.py --source /path/to/original --output /path/to/korean-q8 --bits 8
.venv/bin/python scripts/prepare_model.py --source /path/to/original --output /path/to/korean-mixed4 --bits 4
```

혼합 4비트는 인코더 8비트·디코더 4비트입니다. [현재 M4 실측](docs/BENCHMARKS.ko.md)을 참조하세요.

### 화자 모델 준비

```sh
sh scripts/install_diarization.sh
```

NVIDIA 공식 NeMo-Speech.cpp 0.2.0 Mac Metal 배포판을 내려받아 체크섬을 확인하고, 버전과 해시가 고정된 Nemotron 3 모델을 준비합니다. 회의 중에는 로컬 C ABI로 실행하며 HTTP 서버를 사용하지 않습니다. 화자 모델은 CPU, ASR은 Metal GPU를 사용합니다.

## 사용

Markdown 노트를 연 뒤 `⌘⇧M`으로 시작합니다. 녹음 대상 노트는 시작 시 고정됩니다. 녹음 중 다른 노트로 이동해도 대상이 바뀌지 않습니다. 시작 후에도 본문에 자유롭게 필기할 수 있습니다. 메모를 입력하는 동안 전사 워커는 독립적으로 처리합니다.

`⌘⌥M`으로 상세 보기를 열어 화자 이름과 개별 발언 귀속을 수정합니다. 수동 지정은 자동 결과보다 우선합니다. 중지하면 새 녹음을 끝낸 뒤 남은 구간을 처리합니다. 중간 종료 시 ‘마지막 세션 복구’ 명령으로 원본 오디오를 다시 처리할 수 있습니다.

마이크 녹음은 2초마다 디스크에 저장합니다. 화자 모델의 앞뒤 문맥과 말끝 확인, STT 시간이 추가되므로 전체 표시 지연이 2초라는 뜻은 아닙니다. 긴 발언은 대략 8초 단위로 나눠 처리합니다. 현재는 시스템 소리를 직접 캡처하지 않습니다.

## iCloud 일정과 할 일

아이콘 메뉴 또는 상세 보기 → **캘린더 · 할 일**을 엽니다. 처음에는 macOS 캘린더 권한이 필요합니다. 목록에서 `iCloud · 캘린더 이름`을 선택합니다. 이 Mac에 iCloud 캘린더가 등록돼 있어야 합니다.

제목·시작·종료·메모를 확인하고 ‘캘린더에 저장’을 누르면 macOS가 해당 캘린더로 저장하고 iCloud 동기화를 담당합니다. 향후 7일 일정을 조회할 수 있으며, 플러그인이 만든 일정은 ‘수정’ 버튼으로 갱신합니다. 같은 편집 창에서 저장을 다시 눌러도 같은 고유 ID를 사용합니다. 별도의 외부 캘린더 API나 비밀번호는 필요하지 않습니다.

‘노트에 할 일 추가’는 현재 노트에 기한을 포함한 체크박스를 추가합니다. 일정 내용을 자동으로 추측하거나 사용자 확인 없이 캘린더에 등록하지 않습니다.
