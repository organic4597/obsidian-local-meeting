# Obsidian Local Meeting

외부 추론 API 없이 한국어 회의 음성을 로컬에서 전사하고 Obsidian 노트에 기록하는 데스크톱 플러그인입니다. Apple Silicon Mac 우선 지원.

## 현재 구현: 0.1.0 개발판

- 마이크 PCM 오디오를 8초 WAV 구간으로 먼저 저장하고 SQLite 디스크 큐로 전사 작업 분리
- 로컬 MLX Qwen3-ASR 모델을 한 번 로드한 워커에서 순서대로 전사
- 회의 시작 시 지정한 노트 본문에 시간과 발언 기록
- 수동 화자 지정과 이름 변경, 사용자가 수정·삭제한 발언 보존
- 녹음 중지 후 큐 처리, 앱 재시작 시 세션 복구와 실패 구간 재시도
- Python 워커와 JSONL stdin/stdout 통신. 회의 중 Hugging Face offline mode 사용

**아직 미구현:** 자동 화자 구분, 단어 단위 시간 정렬, 발언 중 임시 텍스트, 경계 중첩 처리, 요약·할 일·ICS, 시스템 오디오 입력, 완성된 설치 패키지. 기본 마이크에 실제 들어오는 소리만 녹음합니다. 고정 구간 전사는 문장 경계에서 누락/중복이 생길 수 있습니다. 자동 화자는 추측하지 않고 `화자 미확정`으로 표시합니다.

## 개발 및 설치

Node.js 22+, Python 3.10+, Apple Silicon Mac 필요.

```sh
npm ci
python3 -m venv .venv
.venv/bin/pip install -r worker/requirements.txt
npm run check
```

`dist/` 내용 전체를 `<Vault>/.obsidian/plugins/local-meeting/`에 복사하고 커뮤니티 플러그인에서 **Local Meeting**을 활성화합니다. 플러그인 설정에 전용 Python 실행 파일, 로컬 MLX 모델 폴더, Vault 외부 오디오 저장 폴더를 지정합니다. 모델 폴더는 `config.json`과 MLX 실행기에서 지원하는 가중치·토크나이저를 포함해야 합니다. 원격 모델 ID는 받지 않습니다.

우선 검증 모델은 `TeamUNIVA/qwen3_asr_1.7b_ko`입니다. Hugging Face 원본 파일을 단순히 폴더에 넣는 것과 MLX 8비트 변환은 다릅니다. 모델 준비와 변환은 회의 전 별도로 수행합니다. 원본 모델과 실행기 라이선스는 [최종 계획서](docs/PLAN.ko.md)를 참조하세요.

1. Markdown 노트를 열고 명령 팔레트 → **Local Meeting: 현재 노트에서 회의 녹음 시작**
2. macOS 마이크 권한 허용. 입력 장치는 워커의 Python 프로세스 기준입니다.
3. 8초마다 기록된 구간이 전사된 뒤 노트에 입력됩니다. 오른쪽 패널에서 최근 발언의 화자를 지정할 수 있습니다.
4. **녹음 중지**는 새 녹음을 종료한 뒤 큐 처리를 계속합니다. 처리 종료 전 워커를 강제 종료하지 마세요.
5. 실패 시 **마지막 세션 복구 및 전사 재시도** 명령. 원본 노트 경로를 바꾸면 현재 개발판에서 자동 복구하지 않습니다.

오디오·전사 DB는 설정한 저장 폴더에 남습니다. 원본은 자동 삭제하지 않습니다. RAM 버퍼는 제한되며 디스크가 따라가지 못하면 명시적으로 녹음을 중지합니다. 마지막 디스크 구간이 저장되기 전 강제 종료하면 RAM에 있던 최대 8초와 OS 입력 버퍼의 오디오는 잃을 수 있습니다.
