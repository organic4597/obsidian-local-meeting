# 회의록 API용 고정 스킬

네 프로젝트의 MIT 지침을 회의록 JSON 정리에 맞게 재구성했다. 실행에 쓰는 고정 지침은 `src/ai-skills.ts`에 있으며 각 폴더에는 참조한 원문 SKILL.md, 필요한 참고 파일, MIT LICENSE, 고정 커밋·파일 해시를 기록한 SOURCE.json이 있다.

| ID | 원본 | 적용 범위 |
|---|---|---|
| summarize-meeting | https://github.com/tomzx/agents | 주제·명시적 결정·후속 조치·미결 사항 추출 |
| stop-slop-ko | https://github.com/limleesol/stop-slop-ko | 정보와 메모 형식을 유지하며 한국어 군더더기 제거 |
| im-not-ai | https://github.com/epoko77-ai/im-not-ai | 고유명사·수치·인용·핵심 의미를 보존하는 보수적 윤문 |
| k-humanizer | https://github.com/evergreentree97/K-Humanizer | 업무 문체·전문 용어·요청과 약속·조건과 확실성 보존 |

## 원본과 다른 점

이 패키지는 각 프로젝트의 전체 에이전트 런타임을 설치하거나 실행하는 것이 아니다. API용 지침만 결합해 한 번의 Responses 요청에 전달한다. 원문의 셸 실행·파일 입출력·에이전트 분업·별도 Markdown 출력은 고정 회의록 계약으로 대체한다.

특히 im-not-ai의 진단·finalize·변경률 측정·verify_gates.py 실행은 포함하지 않는다. API에 보존·윤문 지침을 적용했다고 원본의 수치 검사나 품질 게이트를 통과한 것으로 표시하지 않는다. 필요한 참고 문서는 출처와 변경 근거를 보존하기 위한 것으로 런타임에 동적으로 읽거나 다운로드하지 않는다.

## 우선순위

원문·직접 교정·필기 우선 → 제공된 자료와 근거의 범위 → 화자·시각·담당자·날짜·수치·조건·확실성 → 고정 JSON 스키마 → 활성화한 요약·윤문 지침.

정보 추출에는 요약에 필요한 선별을 허용하지만, 윤문을 이유로 의미를 바꾸거나 근거 없는 내용을 덧붙이지 않는다. 상대 날짜는 기존 회의 시작일 기준 변환 규칙을 따른다. 전사 원문과 사용자가 편집한 문서는 이 기능으로 덮어쓰지 않는다.

스킬 ID·원본 커밋·고정 API 지침·우선순위 계약은 결과 버전의 해시에 포함한다. 외부 파일 경로나 임의 스킬 ID를 지정하는 기능은 제공하지 않는다. 원본 업데이트를 반영하려면 소스와 라이선스를 검토하고 고정 지침을 갱신한 뒤 다시 빌드한다.
